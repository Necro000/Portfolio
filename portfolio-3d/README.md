# ⚡ 3D Cyberpunk Portfolio Web Application

This folder contains the complete client web application for **Sohit Kumar's 3D Portfolio**.

- **Live URL**: [https://portfolio-one-sooty-xxw5ag3on.vercel.app/](https://portfolio-one-sooty-xxw5ag3on.vercel.app/)
- **Main Documentation**: See the [Root README](../README.md) for full architecture specifications, GLSL shader details, and engineering benchmarks.

### Quick Commands

```bash
npm install    # Install dependencies
npm run dev    # Launch local Vite dev server
npm run build  # Create production bundle with manual code-splitting
npm run preview # Preview production build locally
```
